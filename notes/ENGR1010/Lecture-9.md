### Data Types
Turns out the data types aren't interchangeable in C! And the scientific notation is only for floating-point numbers and doubles. But we can covert datatypes
to double (or int if there's no doubles) and do further calculations.

### i++ and ++i
When we do _j=i++_ we actually evaluate _j=i_ first and then add 1 to i! This is very different from _j=++i_ where we assign the return value of the function
_++i_ to _j_.
